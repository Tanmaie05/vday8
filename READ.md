# Day 8: Simple To-Do List

## Objective

The objective of this project is to develop a simple command-line To-Do List application using Python. The application allows users to add, view, update, and remove tasks through a menu-driven interface. The project demonstrates fundamental Python programming concepts, including lists, loops, conditional statements, functions, and menu-driven programs.

## Technologies Used

- Python
- VS Code

## Operations Supported

1. Add Task
2. View Tasks
3. Update Task
4. Remove Task
5. Exit

## Features

- Allows users to add new tasks.
- Stores tasks using a Python list.
- Displays all available tasks.
- Allows users to update existing tasks.
- Allows users to remove tasks.
- Uses separate functions for different operations.
- Provides a menu-driven command-line interface.
- Handles invalid menu choices.
- Handles invalid task numbers.
- Prevents empty tasks from being added.
